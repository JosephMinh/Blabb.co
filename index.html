01Does Blabb need the internet?+

Only during setup and optional model upgrades. The first voice-model download is about 73 MB over HTTPS. Once it is installed, dictation works in airplane mode.

02Which Android versions are supported?+

The current testing build requires Android 13 or newer. Blabb checks the phone’s hardware and available storage during setup before selecting a suitable local model.

03Why does Blabb need AccessibilityService access?+

It lets Blabb identify the active editable field, position the bubble, insert at the cursor, verify the result, and safely undo the latest Blabb insertion. This data is processed on-device and raw field text or app history is not kept.

04Why “display over other apps”?+

Android requires this separate permission so the dictation bubble can float beside the keyboard while another app is open. You can revoke it in Android Settings whenever you like.

05What happens in password fields?+

Nothing. Blabb excludes password and PIN fields, and the bubble does not operate there.

06How large is the first model download?+

About 73 MB for the compact model. Standard and Quality-class phones may download a larger hardware-optimized model later on Wi-Fi; “Use less storage” keeps the compact model.

07Does the bubble work in every text field?+

No universal claim. It appears only when Blabb can identify a safe, compatible field and keyboard surface. For custom editors without a safe target, Blabb can offer its optional Voice Input route.

08What is Blabb Voice Input?+

It is an optional voice-only input route for custom editors and Android’s speech-recognition integrations. It uses the same local model and leaves your ordinary keyboard available; Blabb never enables or selects it on its own.

09What should Samsung users change?+

Set Settings → Apps → Blabb → Battery to Unrestricted, then add Blabb under Battery → Background usage limits → Never sleeping apps. This helps One UI keep text-field detection available.

10When can I try Blabb?+

Blabb is preparing for a private Android beta. Join the waitlist and you’ll receive availability and early-access updates by email.
